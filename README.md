# 🏥 Appointment Booking System (FastAPI)

A comprehensive full-stack web application designed for managing appointment reservations. This project provides a complete set of CRUD operations, allowing users to seamlessly schedule, view, update, and cancel appointments through a modern, responsive user interface.

## 🚀 Technologies

The project is built with a modern tech stack, focusing on performance and clean architecture:

*   **Backend:** Python 3.10+, FastAPI
*   **Database:** SQLite + SQLAlchemy (ORM)
*   **Frontend:** HTML5, CSS3 (Flexbox, Gradients), JavaScript (Vanilla JS)
*   **Templating:** Jinja2
*   **Server:** Uvicorn

## ⚙️ Features

The application implements advanced business logic and robust data validation:

*   **Full CRUD:** Complete functionality to create, read, update, and delete records.
*   **Smart Validation Rules:**
    *   🗓️ **Past Date Restriction:** Blocks scheduling appointments in the past.
    *   ⏰ **Business Hours:** Restricts bookings to working hours only (8:00 AM - 4:00 PM).
    *   🚫 **Conflict Detection:** Prevents double-booking by checking for existing appointments at the requested date and time.
*   **Automatic Sorting:** Appointments are dynamically sorted in chronological order.
*   **Modern UI:** Features a dashboard-style layout (Form + List), responsive design, and interactive error messaging.

## 🛠️ How to run the project

1. **Clone the repository:**
```bash
   git clone [https://github.com/Elenaa78/booking-system-api](https://github.com/Elenaa78/booking-system-api)
```

2.  **Install the required dependencies:**
    ```bash
    pip install fastapi uvicorn sqlalchemy jinja2
    ```

3.  **Run the development server:**
